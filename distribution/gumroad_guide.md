Gumroad is a high-intent marketplace and checkout platform for digital products, templates, and starter kits. Listing Keel on Gumroad gives us immediate access to their built-in discovery and marketplace traffic, complementing our direct Vercel storefront.

- **Name:** Keel — Production-Ready Next.js Starter Kit
- **Price:** $149
- **Description:** 
  Stop wiring Stripe, Supabase, and Tailwind from scratch. Keel gives you a fully tested, production-ready Next.js starter kit with Stripe Checkout, signature-verified webhooks, Supabase RLS authentication, and automated Resend delivery. Deploy in 5 minutes and take your first payment this week.
- **What's Included:**
  - Full source code access via private GitHub repo or direct ZIP download
  - Stripe Checkout integration with webhook idempotency
  - Supabase Auth + Database setup with Row Level Security
  - Resend transactional email setup
  - One-command Vercel deploy configuration

## Execution Steps
1. Navigate to https://gumroad.com and sign up / log in.
2. Create a new product of type **Software / Digital Product**.
3. Set price to $149 USD.
4. Add description and features listed above.
5. Upload cover graphic / screenshot of the Keel landing page.
6. Publish product and link back to https://keel-kappa-six.vercel.app.
